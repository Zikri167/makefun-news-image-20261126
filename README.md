A program that draws a newspaper front page summing up the world's news of Thursday 26 November 2026 in one image: a fuel tanker fire kills 31 on the Cairo ring road, Ukraine hits Russia's Savasleyka airbase, Shenzhou-24 carries the first Pakistani astronaut to Tiangong, Pyongyang expels Swiss staff as Kim orders wider tactical nuclear deployment, BepiColombo reaches Mercury orbit, plus an IN BRIEF strip — drawn procedurally with Python 3.13 stdlib only (own bitmap font + PNG encoder, no network, deterministic).

## Run it

```sh
python3 main.py
```

The program writes the front page to `/output/entry.png` (1024x1024 PNG, under 1 MiB). Set `MAKEFUN_OUTPUT_DIR` to write elsewhere, e.g. `MAKEFUN_OUTPUT_DIR=out python3 main.py`.
